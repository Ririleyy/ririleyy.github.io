Project overview / 01

An engine built into a world.

This fishing game is a complete interactive project built on a focused custom C++/OpenGL engine.

I built the engine around a rasterization pipeline using VAOs and VBOs to organize and draw the game's geometry in real time.

For the game world, I combined a particle system, changing weather, a dynamic sky, and animated water with the core fishing loop and collection feedback.

Engineering / 02

Core systems

The project connects a focused rasterization pipeline with environment systems and gameplay inside one custom engine.

01

Custom engine foundation

Built the game on a custom C++/OpenGL engine with a focused real-time scene and gameplay structure.

02

Rasterization pipeline

Used VAOs and VBOs to manage mesh data and render the game's geometry through a conventional OpenGL rasterization workflow.

03

Particle system

Built a reusable particle system for real-time environmental effects and visual feedback throughout the fishing experience.

04

Weather & sky

Connected changing weather and sky states to give the environment visible time and atmosphere changes.

05

Animated water

Created a responsive water surface that supports the visual identity and moment-to-moment fishing experience.

06

Fishing gameplay

Integrated casting, timing, collection feedback, changing weather, and fish discovery into the custom engine environment.
